# 形状探索 — ダビンチアーチを維持した CP 最大化

2026-10-21 実施。構造形式はダビンチアーチのまま変えず、CP = 最大荷重 / 自重^1.5 が最大になる構成を総当たりで探した。釣り糸と厚紙は、構造に効く場合だけ使う前提にした。
計算は [scripts/explore_davinci.py](../scripts/explore_davinci.py)。FEM・照査・材料値は [構造監査](structural-audit.md) と共通。

```sh
python3 scripts/explore_davinci.py            # 全探索（約 8 分）
python3 scripts/explore_davinci.py --refine   # 上位付近の絞り込み（約 1 分）
```

## 結論

**推奨案（下路・ダビンチ改良案）: CP 1.45、破壊荷重 約 292 N（30 kgf）、重量 約 34 g、荷重/自重 約 870 倍。**
現案（CP 0.10）の約 14 倍。

| 項目 | 現案 | 推奨案 |
| --- | --- | --- |
| 縦材 | 5mm角、各リブ A2列・B1列 | **4mm角**、各リブ A2列・B1列 |
| 横材 | 3mm角 | 3mm角 |
| 交差部 | 接着のみ（接着面 15 mm²） | **両側面に厚紙ガセット**（重ね 10 mm） |
| 床版縦桁（タイ） | 5mm角 | **5×15 縦使い** |
| ハンガー | 釣り糸ナイロン3号・全節点 | 同じ |
| 床版シート | 厚紙 t=0.5 | **なし**（ルール適合の確認が必要） |
| 支配する破壊（P） | 交差部の接着せん断（28 N） | 縦桁 292 N、面内座屈 350 N、めり込み 385 N がほぼ同じ水準 |

- **形の特徴:** 縦材が 4mm角になると δ = 3.5 mm、R = 349 mm になり、縦材長は 145.8 mm（150 mm まで余裕 4.2 mm）。現案の余裕 0.4 mm の問題も解消する。
- **床版シートを載せる場合:** ケント紙 t=0.2 で CP 1.12。

## 何が効いたか

| 変更 | 効果 | 理由 |
| --- | --- | --- |
| 交差部の厚紙ガセット | 破壊荷重が約 4〜9 倍 | 弱点だった木目直交の接着面（15 mm²）を、側面どうしの重ね接着で補える |
| 床版シートをなくす | 重量 −16 g | 荷重は横桁で受けられる。シートは構造的にほぼ働いていない |
| 縦桁を 5×15 縦使い | 破壊荷重が約 3 倍（重量は +8 g） | 補強後に次の弱点になった縦桁の曲げに効く |
| 縦材を 5 → 4mm角 | 軽量化、部材長の余裕が増える | 交差部を補強すると、縦材の断面に余力が出る |
| 釣り糸ハンガー（ナイロン） | バルサ 3mm角と同等以上 | 伸びやすい糸の方が、荷重が強い縦桁へ多く回る。重さはほぼ 0 |

**材料値の感度（推奨案）:**

| 振った材料値 | CP |
| --- | --- |
| 曲げ強度 13.5〜27 MPa | 0.94〜1.71 |
| 重ね接着のせん断 0.5〜2 MPa | 1.07〜1.45 |
| めり込み 0.4〜1.0 MPa | 1.28〜1.45 |
| ヤング率 2.1〜4.3 GPa | 1.24〜1.32 |

## 探索の範囲

全探索で、ルールに適合する 2,708 案を評価した。

| 項目 | 範囲 |
| --- | --- |
| 形式 | 下路（リブ2本＋吊り床版）、上路（アーチ上面を床版とする本来のダビンチ橋＋タイ） |
| 分割数 n | 8、10、12 |
| 縦材・横材 | 3角、4角、5角、5×15 平使い |
| 列数（A/B） | 1/1、2/1、1/2、2/2、3/3 |
| 交差部 | 接着のみ、厚紙ガセット |
| ハンガー | バルサ 3mm角、ナイロン3号（全節点、載荷点のみ） |
| 床版シート | なし、ケント紙 t=0.2 |
| タイ（上路） | 3角、5角 |

絞り込みでは、縦桁（タイ）の断面（4角、5角、5×15 縦使い）と、上路の荷重受け（5×15）を加えた。
ルールは「部材長 150 mm 以下」「有効幅 80 mm 以上」「床版上の有効高さ 80 mm」を自動で判定した。

**上路（本来のダビンチ橋）の最良:** CP 1.01（P 31 N、W 9.7 g）。非常に軽いが、載荷点の横材の曲げとタイで壊れ、下路の推奨案に届かなかった。床版が曲面になる点もルール上の確認が必要。

**形式の限界:** 同じ前提（床版シートなし）のプラットトラスは CP 約 3.2。ダビンチ形式を維持する場合、推奨案はトラスの約半分の CP になる。

## 厚紙なし条件での再探索（2026-10-21、ユーザー決定を受けて）

ユーザーの決定: 推奨案の方向で採用、床版シートなし、**厚紙は使わない**、材料試験は行わない。
推奨案の性能は交差部の厚紙ガセットに依存していたため、厚紙なしの条件で再探索した（`python3 scripts/explore_davinci.py --nocard`、約 2.5 分）。

- **評価した範囲:** 下路で 496 案（ルール適合）。
  - 分割数 8/10/12。
  - 縦材は 4角・5角・5×15 平使い、横材は 3〜5角・5×15 平使い。
  - 荷重が入る節点だけ横材を 5×15 平使いにする案も含めた。
  - 列数、ハンガー、縦桁 5角/5×15 も振った。
- **自立条件の判定:** 分割数と断面の組合せによっては、自立条件と支間 500 mm を同時に満たす R が存在しない。こうした構成を除外する判定を加えた。

**最良案（採用）: 分割数 10、縦材 4mm角、横材 5mm角、各リブ A1列/B1列、ナイロン3号ハンガーを載荷節点のみ、床版シートなし、縦桁 5×15 縦使い。**
CP 0.42、破壊荷重 約 59 N、重量 約 27 g、荷重/自重 約 220 倍。

| 比較 | CP |
| --- | --- |
| 旧案（ダビンチ、厚紙床版、交差部は接着のみ） | 0.08〜0.10 |
| **採用案（厚紙なし）** | **0.42** |
| 分割数 8 で最良の厚紙なし案 | 0.26 |
| 厚紙ガセットありの推奨案（不採用） | 1.45 |

- **分割数 10 が最良になる理由:** 交差部の接着面積（縦材の幅 × 横材の幅）を、部材長 150 mm 以下の範囲で最も大きくできる。横材 5mm角にでき、接着面は 20 mm²（分割数 8 の 3mm角では 12 mm²）。代わりにアーチが高くなる（クラウン約 21 cm）。
- **支配する破壊:** 交差接合の接着せん断で、最も弱い交差部は節点 T3・T7（x≈120・380）。次に弱いのは、荷重が入る T4・T6。
- **材料値の感度:**
  - 交差接合のせん断強度 0.4〜1.0 MPa で、CP 0.34〜0.84。接着の出来がそのまま性能に効く。
  - ヤング率 2.1〜4.3 GPa で、CP 0.38〜0.45。
  - めり込み強度と曲げ強度は、振っても CP が変わらなかった。

## 確認が必要な事項（推奨案の時点）

1. **推奨案を採用して、図面（SVG/STL）と要件定義を更新するか。**
2. **床版シートなしでルールを満たすか**（担当教員に確認）。満たさない場合はケント紙 t=0.2 を使う（CP 1.12）。
3. **載荷点と横桁の位置:** 推奨案の横桁 C3 は x=180.8 で、載荷点 x=175 から 5.8 mm ずれる。シートがない場合、載荷治具は横桁の上に直接載るため、横桁を x=175 に置いて縦桁経由でハンガーへ渡す詳細にする。
4. **製作の手間:** 厚紙ガセットは交差部 54 か所 × 2 枚で、約 110 枚になる。
5. **未検証の項目:** 横倒れ（3D）は未解析。縦桁 5×15 の継手（添え板の重ね 30 mm、両面）も実物の試験が要る。
