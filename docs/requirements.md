# 要件定義 — ダビンチアーチ橋（バルサ模型）

5C 設計製図（2026年後期）の橋梁模型について、AutoCAD で一般図を作図する前段階の要件と簡易設計をまとめる。
数値の正本は [scripts/make_draft.py](../scripts/make_draft.py) の設計パラメータと、その出力（[work/bridge-draft.svg](../work/bridge-draft.svg)・[work/bridge-draft.stl](../work/bridge-draft.stl)）。本書の数値は 2026-10-21 生成の値。
構成を選んだ根拠は [形状探索](design-exploration.md)、評価方法は [構造監査](structural-audit.md) を参照。

凡例: **[確定]** 実施要領・ユーザー指定・ユーザー承認済みの条件 ／ **[仮定]** AI が置いた暫定値（要確認） ／ **[未決]** 決める必要がある事項

## 1. 課題条件（実施要領 R8年度 より）[確定]

| 項目 | 条件 |
| --- | --- |
| 材料 | バルサ材、木工用ボンド、厚紙 |
| 支間 | 500 mm |
| 床版 | 有効幅 80 mm 以上、床版上の有効高さ 80 mm 以上 |
| 部材長 | 一部材の長さ 150 mm 以下 |
| 支点 | 図-3 の三角形の支点で、面ではなく点（線）で支える |
| 載荷試験 | 2点載荷（載荷点間隔 150 mm）。床版上に錘を吊り下げるためのスペースを確保 |
| 反力 | 水平反力を取るため、スパン外にアンカーを取ることを許容 |
| 評価 | CP = 最大荷重 / (橋の重量)^1.5（p.4 の記載。p.8 の式は指数が判読不能）。試験前に重量測定 |
| 図面 | 一般図（側面図・平面図・断面図＋主要寸法）、A4 印刷＋CAD ファイル。AutoCAD 標準 |
| 最終成果物 | 模型、図面、プレゼン（PowerPoint）、作業日誌、報告書（A4・2枚） |

## 2. ユーザー決定事項（2026-10-21）[確定]

- 構造形式はダビンチアーチを維持する。
- **床版は設けない。**
- 厚紙は使わない。
- 材料試験は行わない。
- 2点荷重向けの補強として、ワーレン腹材を採用する。
- 幅は詰める。

## 3. 使用材料 [確定]

- バルサ材: 3 mm 角（縦材・タイ・腹材）、5 mm 角（横材）
- 接着剤（木工用ボンド）
- 手持ちで使わない材料: 4 mm 角、5×15 mm、厚紙、釣り糸

## 4. 構造コンセプト [確定]

- **アーチ:** ダビンチアーチを上弦材とする。縦材（A系・B系）は「端部は横材の上、中央は隣の横材の下」を交互に通り、横材と編む。中間の節点では、同じ系の縦材の端どうしを突き付けて接着する。
- **タイ:** 支点の高さで両端の横材 T0・T8 を結ぶ（3mm 角 2 本）。アーチの水平力を橋の中で打ち消すので、三角支点にかかるのは鉛直反力だけになる。アンカーは使わない。
- **ワーレン腹材:** アーチの節点とタイを、ジグザグの斜材（3mm 角）で結ぶ。2点荷重による曲げを、腹材の軸力で受け持つ。
  - 配置はタイと同じ両側の 2 面。中央の面に置くとアーチの縦材と干渉するため。
- **床版なし:** 錘は、載荷点に最も近い節点 T3・T5 の横材から、両端の吊り糸で吊る。
- **支点:** タイの下面（y=0）が三角支点の頂部に線で接する。T0・T8 は支点の真上（x=0, 500）。
- **荷重の流れ:** 錘 → 横材 T3・T5 → アーチ縦材（交差部）・腹材 → タイ・アーチ → 支点。

## 5. 幾何と部材（現行案）

ダビンチアーチの自立条件: 縦材は直線なので、端部（横材の上、半径 R+δ）と中央（隣の横材の下、半径 R−δ）を結ぶと
**cos α = (R−δ)/(R+δ)**、δ = (縦材断面 + 横材断面)/2。これと支間 500 mm の条件から R が一意に決まる。

| 項目 | 値 |
| --- | --- |
| 分割数 n（節点 T0〜T8） | 8 |
| 縦材 / 横材の断面 | 3 mm 角 / 5 mm 角（δ = 4.0 mm） |
| 節点円半径 R、節点角 α | 322.4 mm、12.71° |
| 縦材長 | 中間 143.6 mm、支点側の端部材 147.6 mm（突き出し 4 mm を含む） |
| クラウン節点高さ | 125.4 mm（支点頂部から） |
| 幅方向配置 | 縦材 A系 z=±6、B系 z=±2（各 2 列）。横材の長さ 22 mm。タイ・腹材の面 z=±9 |
| タイ | 3mm 角 × 2 本、継手 3 か所（各片 ≤150 mm） |
| ワーレン腹材 | 3mm 角、8 か所 × 2 面 = 16 本、長さ 71〜132 mm |
| 重量 | 部材 約 8.0 g ＋ 接着剤（推定 約 1.7 g）＝ 約 9.8 g |

部材ごとの寸法と本数は SVG の部材表を参照。

## 6. 性能評価（2D FEM、材料値は文献の代表値、交差部の柔らかさを考慮）

| 項目 | 値 |
| --- | --- |
| 推定破壊荷重 | 約 44 N（4.4 kgf）。支配は交差部の接着せん断 |
| その他の破壊モード | 面内座屈 66 N、タイ 79 N、腹材の座屈 113 N |
| 荷重/自重 | 約 450 倍 |
| CP（P[N]/W[g]^1.5） | 1.41 |
| 補強の効果 | 同じアーチで補強なしと比べ、破壊荷重 約 4 倍、CP 約 2.4 倍 |

- **材料値の感度:** 交差部の接着せん断強度を 0.4〜1.0 MPa で振ると、CP は 1.13〜2.13。それ以外（ヤング率・曲げ強度・圧縮強度）を振った場合の変化は小さい。
- **未検証:** 横倒れ（3D 座屈）は概算のみ。幅 22 mm と細いので、実物では横倒れに注意。材料試験は行わない方針。

## 8. 未決定事項・要確認

1. **[要確認] 床版なしで出場できるか**：実施要領は「床版の有効幅 80 mm」「床版上に錘を吊り下げるスペース」と、床版を前提に書かれている。担当教員に確認する。
2. **[要確認] 錘の吊り方**：横材 T3・T5 の両端から吊る前提。載荷治具をどう掛けるか、載荷点からの 4 mm のずれが許されるか。
3. **[未決] 接合の詳細**：
   - 交差部の接着、同系の縦材の突き付け
   - 腹材の端（横材の下面・タイの上面に重ねて接着）
   - タイの継手
4. **[未決] 横倒れ対策**：幅 22 mm で、横倒れの照査は概算のみ。必要なら幅を広げる（幅 60 mm で CP 約 1.2 の見込み）。
5. **[仮定] 密度**：バルサ 0.16 g/cm³、接着剤 0.03 g/接合。実材を量って置き換える。

## 9. AutoCAD 作図への引き継ぎ

- 座標系: x=橋軸方向（左支点 0）、y=鉛直（支点頂部 0）、z=幅員方向（中心 0）。SVG は 1単位=1 mm。側面図は 1:1、平面図は幅方向のみ 2 倍、断面図は 3 倍。
- 節点座標・部材長は `python3 scripts/make_draft.py` の出力と SVG の部材表を参照する。
- 作図対象: 側面図・平面図・断面図（A-A クラウン T4、B-B 節点 T1）、部材表、表題欄。高さ約 13 cm・長さ約 52 cm で、A4 には 1:2.5〜1:3 で収まる。
