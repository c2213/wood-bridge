# 要件定義 — ダビンチアーチ橋（バルサ模型）

5C 設計製図（2026年後期）の橋梁模型について、AutoCAD で一般図を作図する前段階の要件と簡易設計をまとめる。
数値の正本は [scripts/make_draft.py](../scripts/make_draft.py) の設計パラメータと、その出力（[work/bridge-draft.svg](../work/bridge-draft.svg)・[work/bridge-draft.stl](../work/bridge-draft.stl)）。本書の数値は 2026-10-21 生成の値。
構成を選んだ根拠は [形状探索](design-exploration.md)、性能評価の方法は [構造監査](structural-audit.md) を参照。

凡例: **[確定]** 実施要領・ユーザー指定・ユーザー承認済みの条件 ／ **[仮定]** AI が置いた暫定値（要確認） ／ **[未決]** 決める必要がある事項

## 2. 使用材料 [確定]

- バルサ材: 3 mm 角、4 mm 角、5 mm 角、5×15 mm
- 接着剤、釣り糸
- **厚紙は使わない**（床版シート・交差部の補強とも不使用。2026-10-21 ユーザー決定）

## 3. 構造コンセプト [確定]

- **形式:** ダビンチアーチ（レオナルド橋型の相互支持アーチ）。短い直線材を「端部は横材の上、中央は隣の横材の下」に交互に組み、材同士が押さえ合って弧を作る。
- **床版位置:** 支点の高さに置く**下路式**。アーチは床版の両外側に**リブ2本**として立てる。各リブは A系・B系の縦材 1 列ずつ。
- **床版:** **床版シートは使わない。** 載荷点 x=175・325 の真下に載荷横桁（5×15 縦使い）を置き、載荷治具はこの横桁に直接載る。
- **水平反力:** 縦桁（5×15 縦使い）を**タイ**として使い、アーチの水平力を橋の中で打ち消す（タイドアーチ）。支点には鉛直反力だけがかかる。アンカーは使わない。
- **支点:** 縦桁と端横桁の下面（y=0）が三角支点の頂部に線で接する。アーチ端部の横材 T0/T10 は支点の真上（x=0, 500）に置く。
- **吊り:** 釣り糸ハンガーで載荷横桁の両端を、直近の節点 T4/T6 から吊る。ハンガーは載荷節点のみ。
- **横つなぎ:** 床版上 80 mm より高い節点 T2〜T8 だけ、リブ間を 3mm 角のつなぎ材で結ぶ（横倒れ防止）。
- **荷重の流れ:** 載荷治具 → 載荷横桁 → 縦桁端部 → 釣り糸ハンガー → 節点 T4/T6 → アーチ → 支点。水平力はアーチ端部から縦桁（タイ）へ流れる。

## 4. 幾何と部材（現行案）

ダビンチアーチの自立条件: 縦材は直線なので、端部（横材の上、半径 R+δ）と中央（隣の横材の下、半径 R−δ）を結ぶと
**cos α = (R−δ)/(R+δ)**、δ = (縦材断面 + 横材断面)/2。これと支間 500 mm の条件から R が一意に決まる。

| 項目 | 値 |
| --- | --- |
| 分割数 n（節点 T0〜T10） | 10 |
| 縦材 / 横材の断面 | 4 mm 角 / 5 mm 角（δ = 4.5 mm） |
| 節点円半径 R、節点角 α | 258.7 mm、15.03° |
| 縦材長（節点間 136.5 + 突き出し 4×2） | 144.5 mm（150 mm まで余裕 5.5 mm） |
| クラウン節点高さ / 横桁上面 | 210.4 mm / 15.0 mm（支点頂部から） |
| 幅方向配置 | リブ中心 z=±51.5（A系 ±54、B系 ±49）、リブ内面間の純幅 90、全幅 116 |
| 縦桁（タイ） | 5×15 縦使い、z=±51.5、継手 3か所（各片 129.5 mm） |
| 横桁 | 載荷横桁 5×15 縦使い（x=175・325）、端横桁 5 角（x=0・500）、長さ 98 mm |
| 概算重量 | 約 25 g（接着剤を除く）。うち縦桁 12.4 g、アーチ縦材 7.4 g |

部材ごとの寸法と本数は SVG の部材表を参照。

## 5. 性能評価（2D FEM、材料値は文献の代表値）

交差部の扱いで結果が大きく変わる。現実的な柔らかさを入れたモデル（2026-10-21 更新）を正とする。

| 項目 | 交差部を柔らかく（現実的、正） | 交差部を剛（旧評価、控えめ） |
| --- | --- | --- |
| 推定破壊荷重 | 約 111 N（11 kgf） | 約 59 N |
| 支配する破壊 | 縦桁の横倒れ座屈（Lb≈183 mm）、次いで縦桁の曲げ 119 N | 交差接合の接着せん断 |
| 荷重/自重 | 約 420 倍 | 約 220 倍 |
| CP（P[N]/W[g]^1.5） | 0.80 | 0.42 |
| アーチ分担率 | 約 25%（残りは縦桁が梁として運ぶ） | — |

- **交差部の柔らかさ:** 横材のころがりせん断剛性（G_LT/10）と、繊維直角方向のヤング率から見積もった。剛として扱うと交差部に力が集まり、破壊荷重を過小に評価する。
- **アーチ分担率が低い:** 釣り糸ハンガーが伸びやすいため、アーチに流れる荷重は約 25% にとどまる。アーチを主に効かせる案との比較は [形状探索](design-exploration.md) の最終節を参照。
- **未検証:** 横倒れ（3D 座屈）。縦桁の横倒れ座屈は簡易式で照査した。材料試験は行わない方針。

## 7. 未決定事項・要確認

1. **[要確認] 床版シートなしでルールを満たすか**：「床版の有効幅 80 mm 以上」を、載荷横桁（幅 98 mm）で満たすと解釈している。担当教員に確認する。
2. **[要確認] 錘の吊り下げ方法**：載荷治具が載荷横桁にどう載り、錘の糸がどこを通るか。横桁の間は空いている。
3. **[未決] 縦桁（タイ）の継手**：5×15 材を3か所で継ぐ。添え板（バルサ）の重ね継手の寸法。
4. **[未決] 交差部の接合方法**：接着のみ（現案）。相欠きにすると δ が小さくなり、アーチの幾何が変わる。
5. **[未決] 釣り糸の結び方と取付け位置**：横材 T4/T6 の下面（リブ中心）から、載荷横桁の端部へ。
6. **[未決] 横倒れ対策**：つなぎ材以外に、端部の門構え（T1〜T2 付近）が必要か。
7. **[仮定] 密度**：バルサ 0.16 g/cm³。実材を量って置き換える。

## 8. AutoCAD 作図への引き継ぎ

- 座標系: x=橋軸方向（左支点 0）、y=鉛直（支点頂部 0）、z=幅員方向（中心 0）。SVG は 1単位=1 mm（全図 1:1）。
- 節点座標・部材長は `python3 scripts/make_draft.py` の出力と SVG の部材表を参照する。
- 作図対象: 側面図・平面図・断面図（A-A クラウン T5、B-B 節点 T1）、部材表、表題欄。高さ約 22 cm・幅 52 cm なので、A4 に収める縮尺は 1:3〜1:4 程度。
