# 要件定義 — ダビンチアーチ橋（バルサ模型）

5C 設計製図（2026年後期）の橋梁模型について、AutoCAD で一般図を作図する前段階の要件と簡易設計をまとめる。
数値の正本は [scripts/make_draft.py](../scripts/make_draft.py) の設計パラメータと、その出力（[work/bridge-draft.svg](../work/bridge-draft.svg)・[work/bridge-draft.stl](../work/bridge-draft.stl)）。本書の数値はベース案（2026-10-21 生成）の値。

凡例: **[確定]** 実施要領・ユーザー指定の条件 ／ **[仮定]** AI が置いた暫定値（要確認） ／ **[未決]** 決める必要がある事項

## 1. 課題条件（実施要領 R8年度 より）[確定]

| 項目 | 条件 |
| --- | --- |
| 材料 | バルサ材、木工用ボンド、厚紙 |
| 支間 | 500 mm |
| 床版 | 有効幅 80 mm 以上、床版上の有効高さ 80 mm 以上 |
| 部材長 | 一部材の長さ 150 mm 以下 |
| 載荷試験 | 2点載荷（載荷点間隔 150 mm）。床版上に錘を吊り下げるためのスペースを確保 |
| 反力 | 水平反力を取るため、スパン外にアンカーを取ることを許容 |
| 評価 | CP = 最大荷重 / (橋の重量)^1.5（p.4 の記載。p.8 の式は指数が判読不能）。試験前に重量測定 |

| 最終成果物 | 模型、図面、プレゼン（PowerPoint）、作業日誌、報告書（A4・2枚） |

## 2. 使用材料 [確定：ユーザー指定]

- バルサ材: 3 mm 角、4 mm 角、5 mm 角、5×15 mm
- 接着剤、厚紙、釣り糸

## 3. 構造コンセプト

- **形式 [確定]:** ダビンチアーチ（レオナルド橋型の相互支持アーチ）。短い直線材を「端部は横材の上、中央は隣の横材の下」に交互に組み、材同士が押さえ合って弧を作る。短材（≤150 mm）しか使えない課題条件と相性がよい。
- **床版位置 [仮定]:** 上路式（アーチの上に床版を載せる）。理由:
  - 床版上に部材がないため「床版上有効高さ 80 mm」を無条件に満たす。
  - 下路式・中路式では、支点付近でアーチの横材が床版を横切り、有効高さ 80 mm を確保できない。
- **荷重の流れ:** 載荷点 → 床版（厚紙）→ 床版縦桁 → 鉛直材 → 横材 → A系・B系縦材（アーチ）→ 支点。アーチの水平反力は**スパン外アンカー**で受ける（許容条件を利用）。

## 4. 幾何（ベース案）

ダビンチアーチの自立条件: 縦材は直線なので、端部（横材の上、半径 R+δ）と中央（隣の横材の下、半径 R−δ）を結ぶと
**cos α = (R−δ)/(R+δ)**、δ = (縦材断面 + 横材断面)/2。これと支間 500 mm の条件から R が一意に決まる。

| 項目 | 値 |
| --- | --- |
| 分割数 n（節点 T0〜T8） | 8 |
| 縦材 / 横材の断面 | 5 mm 角 / 3 mm 角（δ = 4.0 mm） |
| 節点円半径 R、節点角 α | 322.4 mm、12.71° |
| 縦材長（節点間 143.6 + 突き出し 3×2） | **149.6 mm（上限まで余裕 0.4 mm）** |
| 節点ライズ / 床版上面高さ | 120.3 mm / 127.9 mm（支点上面から） |
| 幅方向配置 | A系 z=±30、B系 z=±10、縦桁・鉛直材 z=±40、横材長 90 |
| 床版 | 厚紙 t=0.5、幅 90、節点位置で4分割（113.6 / 138.4 / 138.4 / 113.6） |
| 概算重量 | 約 33 g（うち厚紙床版 約 16 g。接着剤を除く） |

## 6. 未決定事項・要確認

1. **[未決] 床版位置**：上路式でよいか（本案の前提）。
2. **[要確認] 錘の吊り下げ方法**：載荷治具が床版中央から吊るのか、側方から吊るのか。中央吊りだと横材 T3/T5 との離れが 2.3 mm しかない。
3. **[要確認] 支点・アンカーの形状**：支点の掛かり長、アンカーの取り方。現案はアーチ端が支点の角に載るだけで、縦材端が支点上面より 0.6 mm 下がる。支承部の詳細は AutoCAD 作図時に決める。
4. **[未決] 縦材長の余裕**：ベース案は余裕 0.4 mm で、切断誤差を考えると厳しい。突き出しを減らすか、4 mm 角縦材案に替えるか。
5. **[要確認] 厚紙にも 150 mm 制限が適用されるか**：現案は安全側で分割。
6. **[未決] 床版の軽量化**：厚紙床版が全体重量の約半分。CP は重量の 1.5 乗に効くため、厚紙の厚さ・肉抜き・横桁方式を検討する。
7. **[仮定] 密度**：バルサ 0.16 g/cm³、厚紙 0.70 g/cm³。実材を量って置き換える。
8. **[未決] 釣り糸の用途**：候補は (a) 両支点間のタイ（アンカー不要化）、(b) 側面の X 形ブレース（横倒れ・ねじれ対策）。現案では未使用。
9. **[未決] 接合方法**：交差部の相欠き・厚紙ガセットの有無（相欠きは δ を小さくし、幾何が変わる）。

## 7. AutoCAD 作図への引き継ぎ

- 座標系: x=橋軸方向（左支点 0）、y=鉛直（支点上面 0）、z=幅員方向（中心 0）。SVG は 1単位=1 mm（断面図のみ 2倍）。
- 節点座標・部材長は `python3 scripts/make_draft.py` の出力と SVG の部材表を参照する。
- 作図対象: 側面図・平面図・断面図（A-A クラウン、B-B 節点 T1）、部材表、表題欄。A4 に収めるため縮尺は 1:5 程度を想定。
